**Team Composition:** 5 Members $\rightarrow$ 6 Core Features (including user-facing AI)

## Required Submission Components

1. **Functioning Flutter Application:**
   - 6 core user-facing features (Auth, splash, About, Settings excluded).
   - Async operations with visible loading, empty, and error states.
   - At least one form with input validation and clear error feedback.
   - Data persistence via local storage or Firebase cloud services.
2. **AI-Powered Feature:**
   - Direct end-user interaction (Activity suggestion helper).
   - Graceful failure with deterministic catalog fallback and strict RA 10173 data minimization.
3. **Software Documentation Package:**
   - Overview & Introduction (Stack with specific versions).
   - Functional Requirements, UI/UX Prototypes, and Screenshots.
   - **Topic Coverage Matrix:** Code-to-curriculum mapping (Layout, Navigation, Forms, Async/API, Persistence, AI).
   - **AI Feature Specification:** Service, inputs, sample outputs, failure handling, relevance, privacy.
   - **AI Usage Log:** Tabular log of AI-assisted code generation.
   - **Individual Reflections:** Half-page per member covering features built, bug fixed, and future improvements.
4. **GitHub & Peer Review Governance:**
   - Forked repository with feature branches and meaningful commits across all 5 members.
   - Pull requests reviewed by at least one teammate prior to merging into `main`.
