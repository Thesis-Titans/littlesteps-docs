## Courses & Deliverable Packages

### 1. [CIT 246 — IT Project Management](cit246/README.md)
A single Project Management Plan for a 6–12 month project for a real organization. The group plans the project; no code is required.
- **[Checkpoint 1: One-Page Project Concept](cit246/checkpoint-1-concept.md):** organization, problem, proposed system and possible sponsor (due October 14, 2026; Arial 11, A4). Must be approved before the full plan starts.
- **Checkpoint 2:** charter, stakeholder register (8+ entries including an opponent) and scope statement (template sections 3–6); date to be announced.
- **Checkpoint 3:** WBS (3+ levels with dictionary), schedule (network diagram and Gantt with critical path) and cost baseline (sections 7–9); date to be announced.
- **Final Project Management Plan:** all 17 template sections, 25–40 pages, one PDF named `CIT246_FinalProject_GroupName.pdf` on Google Drive plus a printed copy; 15-minute presentation with every member speaking. Graded on five 20-point criteria.

### 2. [CC 207B — Applications Development and Emerging Technologies](cc207b/README.md)
A Flutter application with at least six core features (including one user-facing AI feature), presented with a live demo and an Individual Code Defense.
- **Software documentation:** overview with the technology stack and versions; functional requirements (packages and their purpose, low- and high-fidelity prototypes, core features with screenshots, Topic Coverage Matrix, AI Feature Specification); future enhancements and roadmap; AI Usage Log and individual reflections as appendices.
- **Presentation:** 5–10 minutes with a live demo, a backup video, and known limitations; 2–3 minutes of code defense per member.
- **GitHub:** fork of the instructor's repository, feature branches, teammate-reviewed pull requests, secrets excluded, README with setup steps. Collaboration is graded from the commit and pull-request history.
- **Self and peer assessment:** 10% self and 20% peer, with peer ratings based on contributions visible in GitHub.
- **AI Use Policy:** AI-generated code, text content and image assets must be recorded in the AI Usage Log; generating the application wholesale is not allowed.
