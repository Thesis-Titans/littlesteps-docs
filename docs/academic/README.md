# LittleSteps Academic Course Deliverables

**Status:** Canonical Academic Deliverables Index

This directory contains the academic course evaluation packages and deliverables for **LittleSteps**, fulfilling the separate requirements of three coordinated courses in the West Visayas State University (WVSU) Bachelor of Science in Information Technology (BSIT) program.

---

## Courses & Deliverable Packages

### 1. [CIT 246 — IT Project Management Plan](cit246/README.md)
Governs overall project planning, lifecycle management, scheduling, and risk analysis for the system.
- **[Checkpoint 1: One-Page Project Concept](cit246/checkpoint-1-concept.md):** Client organization, problem description, proposed system, and sponsor proposal (due October 14, 2026; Arial 11, A4).
- **Checkpoint 2 (Upcoming):** Project Charter, Stakeholder Register (8+ entries with opponent), and Scope Statement.
- **Checkpoint 3 (Upcoming):** Work Breakdown Structure (3+ levels with dictionary), Schedule Network/Gantt, and Cost Baseline.
- **Final Project Management Plan (Upcoming):** 25–40 page comprehensive plan across all 17 template sections (due December 2, 2026).

### 2. [CC 207B — Applications Development and Emerging Technologies](cc207b/README.md)
Covers the Flutter mobile application, user-facing AI recommendation helper, live demonstration, and individual code defense.
- **Topic Coverage Matrix (Upcoming):** Mapping curriculum topics (Layout, Navigation, Forms/Validation, Async/API, Persistence, AI) directly to code.
- **AI Feature Specification (Upcoming):** Documentation of the constrained AI recommendation helper, prompt schemas, and deterministic fallbacks.
- **AI Usage Log (Upcoming):** Log of all AI-assisted code snippets, debugging, and synthetic test fixtures.
- **Individual Reflections (Upcoming):** Half-page member reflections on contributions and bug fixes.

### 3. [CIT 210 — Web Systems and Technologies](cit210/README.md)
Covers the React web client, shared Node.js/TypeScript API, and database integration.
- **Technical Contract:** Canonical OpenAPI contract maintained in the [API repository OpenAPI specification](https://github.com/Thesis-Titans/littlesteps-api/blob/main/openapi/openapi.yaml).
- **Local Onboarding:** Step-by-step full-stack local setup in [Developer Onboarding Guide](../getting-started.md).
